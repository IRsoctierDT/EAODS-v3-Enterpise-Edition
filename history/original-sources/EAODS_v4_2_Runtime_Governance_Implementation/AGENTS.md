# AGENTS.md

## Repository Mission

This repository contains the Enterprise AI Operator Documentation Suite v3.2: a governed multi-agent AI operating system for business operations, cybersecurity, compliance, portfolio documentation, knowledge management, and executive execution.

## Global Agent Rules

All agents must:

1. Preserve YAML front matter.
2. Maintain enterprise documentation structure.
3. Identify assumptions.
4. Distinguish legal requirements, regulatory expectations, contractual obligations, internal policy, and best practices.
5. Add or update QA checklists for major deliverables.
6. Add case studies where relevant.
7. Avoid unreviewed high-impact actions.
8. Preserve source code appendices unless intentionally updating them.
9. Use semantic versioning.
10. Update the README or manifest when adding major artifacts.

## Human Approval Required

Human approval is required for:

- legal interpretation,
- compliance conclusions,
- production security changes,
- financial commitments,
- client-facing commitments,
- privacy-affecting decisions,
- destructive actions,
- publication of sensitive material.

## Commit Discipline

Use commit messages such as:

- `docs: expand orchestrator governance model`
- `docs: add EAODS evaluation rubric`
- `docs: add agent security guardrails`
- `docs: add compliance case study framework`
- `chore: update documentation manifest`
