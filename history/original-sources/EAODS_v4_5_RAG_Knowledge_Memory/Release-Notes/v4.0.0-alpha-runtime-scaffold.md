# EAODS v4.0.0-alpha Runtime Scaffold Release Notes

## Summary

This release introduces the first runnable EAODS runtime scaffold.

## New Capabilities

- CLI entry point
- Agent registry
- Request routing
- Workflow state generation
- Risk-tier action classification
- Runtime handbook generator
- Markdown artifact scorer
- Release notes generator
- Pytest suite
- GitHub Actions runtime test workflow

## Why This Matters

EAODS is no longer only an enterprise documentation suite. It now has a minimal operational control plane that can be extended into a true local agent operating system.

## Safe-by-Design Boundary

The scaffold does not perform destructive actions, execute arbitrary shell commands, deploy systems, or access secrets.

## Next Version

`v4.0.1-alpha` should add:

- richer YAML validation,
- persistent workflow history,
- evidence registry,
- RAG ingestion metadata,
- dashboard output,
- automatic repository map generation.
