# EAODS v3.2.0-alpha Release Notes

## Release Summary

This alpha release merges the earlier **EAODS v3 Enterprise Edition** handbooks with the **EAODS v3.2 Enhanced Operator Edition** control-plane, governance, security, evaluation, and publishing enhancements.

The result is a more complete documentation platform rather than a loose collection of Markdown files.

## Included Capability Areas

- Enterprise standards
- System architecture
- Orchestrator control-plane expansion
- Core agent handbooks
- Business agent handbooks
- Security agent handbooks
- Compliance agent handbooks
- Executive operations handbook
- Knowledge management handbooks
- Case-study framework
- Risk and control templates
- Security guardrails
- Evaluation rubric
- QA pipeline
- GitHub Actions documentation workflow
- MkDocs publishing configuration
- Repository operating instructions via `AGENTS.md`

## Strategic Improvement

This release improves EAODS in four ways:

1. **Governance:** Formalizes approval gates, risk tiers, evidence requirements, and agent operating rules.
2. **Evaluation:** Adds measurable scoring for agent outputs and handbooks.
3. **Security:** Adds safety controls for agentic execution and repository operations.
4. **Publishing:** Adds MkDocs and GitHub Actions foundations for public or private documentation deployment.

## Current Release Status

`v3.2.0-alpha` is suitable for internal review, portfolio staging, and repository organization. It should not yet be treated as a final commercial release.

## Required Review Before Public Release

- Remove sensitive or private data.
- Validate source-code appendices.
- Confirm licensing strategy.
- Confirm public/private repository separation.
- Add authoritative references where regulatory statements are made.
- Run Markdown QA.
- Score each handbook using the EAODS Agent Evaluation Rubric.

## Next Recommended Version

`v3.2.1` should focus on correcting structure, improving citations, and expanding the Orchestrator handbook.

`v3.3.0` should expand each agent handbook from alpha handbook to full enterprise manual.
